# go-ai

AI를 업무에 들이고, 굴리고, 통제하는 법을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 경영자·관리자·실무자의 관점입니다. 국내 법·제도(AI 기본법, 개인정보 보호법, 저작권법, 업권 지침)를 뼈대로 하고 EU AI Act, NIST AI RMF, ISO/IEC 42001과 비교합니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도, 확인한 법령·기준 목록, 튜터의 행동 규칙만 있습니다. 도식, 조사 자료를 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다. 사용 정책, AI 목록, 판단 기록 같은 업무 산출물 초안도 내 답으로 함께 씁니다.

> **학습용이며 법률 자문이 아닙니다.** 법령·가이드라인은 자주 바뀝니다. 튜터는 확인한 출처와 조회일을 함께 말하지만, 실제 사안의 결론은 사내 법무나 전문가, 소관 기관에 확인하세요.

## 시작하기

준비물은 Git, [GitHub CLI](https://cli.github.com)(`gh`), Claude Code 또는 Claude Desktop입니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-ai
```

**Claude Code**

```bash
cd ~/Desktop/go-ai
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-ai` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 지금 맡은 일과 AI를 써 본 경험을 짧게 묻고, 영역마다 업무 상황 문제를 하나씩 풀어 출발점을 찾습니다.
2. 모듈마다 먼저 상황 문제로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML을 만들어 가며 익힙니다. 업무 산출물 초안은 `learner/work/`에 쌓입니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고, 복습할 것이 있으면 복습 질문 하나로 이어갑니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」, 「우리 회사 사례로 해 보자」처럼요. 회사 이름·사람 이름·수치는 바꿔 말해도 됩니다.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도 |
| [curriculum/sources.md](curriculum/sources.md) | 확인한 법령·기준과 조회일 |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 업무 산출물 초안. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/work`의 Markdown 초안을 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다. 웹 조사 때는 질문과 주소가 외부 서비스로 전달되므로, 회사 기밀이나 개인정보는 대화에 넣지 마세요.

## 관련 워크스페이스

AI 기술 구현은 go-develop, AI 보안 기술과 개인정보·정보보호 전반은 go-security, 노동법은 go-hr, 내부통제 일반은 go-control, 구매 절차는 go-scm, 프로젝트 관리는 go-project-management, 투자 평가는 go-finance가 다룹니다. 이 워크스페이스는 그 주제를 깊게 다루지 않고 관리자가 알아야 할 판단까지만 다룹니다.
